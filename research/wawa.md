# 蛙蛙写作 竞品分析

> 调研对象：蛙蛙写作（wawawriter.com），运营方：杭州引力智航科技有限公司
> 调研时间：2026-10-22　调研方式：官网公开页面 + 第三方评测站摘要（未登录、未付费实测）

## 一句话定位

面向中文网文与短剧/漫剧创作者的"小说 → 剧本 → 视频"一体化故事 IP 生产工作台，而不只是一个 AI 续写工具。

## 目标用户

| 人群 | 需求场景 |
| --- | --- |
| 连载网文作者 | 把人物、背景、大纲、卷章放在同一工作台长期维护，逐章续写/扩写/润色 |
| 短剧、漫剧团队 | 先把小说整理成剧本草稿，再进入视频生产链路试跑 |
| 编辑与内容工作室 | 用 AI 出情节分支、场景候选、修改建议，人做终审 |
| 小说转短剧的改编需求方 | 从已有小说提取剧情与人物关系，生成改编草稿 |

不适合：希望"一句话生成即可投稿"的用户；上传无授权作品做商业改编的用户。

## 功能矩阵

| 功能 | 说明 | 亮点程度 |
| --- | --- | --- |
| 长短篇小说工作台 | 从题材、人物、背景、大纲、章节起步，提供续写、扩写、润色、AI 对话 | ★★★★ |
| 项目设定与连续写作 | 保存角色、势力、背景、卷章、目标读者等项目上下文，支撑长篇一致性 | ★★★★ |
| 剧本创作 | 剧本项目、剧集、细纲管理，按短剧/漫剧形式组织场景与对白 | ★★★★★ |
| 小说转剧本 | 从小说提取剧情与人物关系，按所选模型与类型生成改编草稿 | ★★★★★ |
| 漫剧视频 | 小说或剧本继续转入视频生产链路 | ★★★★ |
| 拆书分析 | 作品结构分析、提示工具、工作流市场，用于找结构与改稿方向 | ★★★★ |
| 投稿中心 | 站内投稿入口，连接创作与分发 | ★★★ |
| 导入/导出/回收站 | 卷章、草稿、作品管理，支持恢复 | ★★★ |
| 工作流市场 / AI 工具广场 | 复用他人工作流与工具模板 | ★★★ |

## 工作流拆解（灵感到成稿）

1. **立项目**：选题材与类型，建项目（长篇 / 剧本）。
2. **填设定**：人物、势力、背景、时间线、目标读者，作为后续生成的上下文基准。
3. **搭大纲**：卷 → 章 → 细纲，先出结构再落字。
4. **逐章生成**：续写 / 扩写 / 润色，AI 对话辅助改稿，人工审稿并回写新设定。
5. **改编分叉**（可选）：小说转剧本，抽取剧情与人物关系，生成短剧/漫剧剧本草稿。
6. **视频化**（可选）：剧本继续进漫剧视频链路，按任务页面选模型、素材、时长。
7. **导出交付**：导出阶段版本，同步本地备份。

关键洞察：蛙蛙的护城河不在单点生成质量，而在**上下文资产（设定/细纲）可跨阶段复用**——写到剧本、写到视频都不必重新交代背景。

## 独特之处

- **短剧/漫剧剧本优先**：剧集、细纲、场次、对白是原生结构，不是把小说文本硬套剧本格式。
- **小说转剧本**：中文网文改编为短剧剧本的专用链路，配合"孤星"等剧本系列工具。
- **拆书**：把成熟作品拆成可复用的结构，反哺自己的大纲。
- **文风与设定体系**：以项目设定 + 细纲维持长篇文风与人物一致性，比单次对话更适合百万字连载。
- **小说—剧本—视频连续生产**：少见地把三段落放在同一平台，素材不落地转手。

## 优点

1. **赛道卡位准**：中文网文 + 短剧 + 漫剧，术语与工作流贴合本土创作者，通用大模型做不到。
2. **上下文资产可复用**：设定、人物、细纲跨小说/剧本/视频复用，迁移成本高，留存天然强。
3. **链路完整**：小说 → 剧本 → 视频一条线走完，减少跨工具搬运与背景重述。
4. **长篇友好**：卷章结构与设定库比聊天式工具更适合连载维护。
5. **低门槛试用**：免费权益可先跑小项目验证，再决定会员或蛙币投入。

## 缺点

1. **计价不透明**：会员 + 蛙币 + 无限卡 + 专项任务四层叠加，用户难算出真实成本。
2. **"无限"有边界**：拆书、转剧本、漫剧视频与高级模型基本都在无限卡之外，易生预期落差。
3. **质量仍需人工兜底**：长篇一致性漂移、剧本制作可行性、视频质量都要逐项检查。
4. **权利与数据不清晰**：版权归属、训练用途、第三方处理、服务器留存与永久删除缺乏明确公开说明。
5. **无公开 API/SDK**：无法做生产级集成或批量自动化，团队协作与二次开发受限。

## 对我们的启示

1. **卖"资产"而非"字数"**：让用户的设定/大纲/文风成为沉淀资产，是留存与付费的真正支点；我们应把项目设定库做成一等公民。
2. **用结构差异化打通用模型**：短剧剧集、细纲、场次这类垂直结构，是通用大模型无法直接提供的护城河。
3. **计价要一句话讲清**：蛙蛙最大的口碑风险来自四层计费。我们若做订阅 + 额度，必须提供单任务预估与失败不扣费。
4. **跨阶段复用是增长杠杆**：小说→剧本→视频的连续性让用户越用越难走，可作为路线图主线。
5. **把"拆书/仿写"做成合规能力**：拆结构而非抄文本，同时明确版权与授权提示，既好用又降风险。
