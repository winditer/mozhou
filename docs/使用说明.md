# 墨舟 使用说明

面向作者的操作手册。读完这一篇，你能从零写完一本书并导出成品。

---

## 一、安装与首次启动

- **macOS 12 Monterey 及以上**：打开 `Mozhou-1.6.0-arm64.dmg`，把「墨舟」拖进「应用程序」。
  > 安装包没有做 Apple 公证。首次打开如果提示「无法验证开发者」，右键点应用 → 打开 → 再点「打开」；或到「系统设置 → 隐私与安全性」里点「仍要打开」。
- **Windows**：运行 `Mozhou-Setup-1.6.0.exe`。如果 SmartScreen 拦了一次，点「更多信息 → 仍要运行」。

第一次打开会直接进入**设置页**，先去配一个模型；配好之后（或已经有作品时）再打开都会落在**书架**。

设置页顶部有一条「先在这里配好模型，再去书架开始写作」的引导条，点右边的 **去书架** 就去开第一本书；
其它时候想回书架，点标题栏左上角「墨舟」旁边的 **书架** 按钮。

- 封面大小：书架右上角的 `小 / 中 / 大` 三档（对应 100 / 150 / 196px，默认「中」），点一下就记住。
- 改作品信息：卡片右上角 `⋯` → **编辑信息**，可以改书名、作者、题材、一句话简介、故事梗概和封面色；写作页左侧栏最下面的 ⓘ 也能打开同一个窗口。

## 二、配置模型（1 分钟）

墨舟没有内置额度，用的是**你自己的 API Key**。钱直接付给模型厂商，墨舟不抽成、不中转。

1. 点右上角 ⚙ → 左侧「渠道与模型」→ 右上「+ 新增渠道」。
2. 选一个预设，比如 **DeepSeek**（中文写作性价比最高，输入 ¥2 / 输出 ¥8 每百万 token 量级）。
3. 粘贴 API Key。**Key 会用系统钥匙串加密存到本机**，不会明文落盘。
4. 模型列表就在这个弹窗里：预设会带几个常用模型，也可以手填模型 ID，或点「从接口拉取」拿厂商的真实列表；
   停用的模型不会出现在任务分配里。**渠道和模型一起保存**，取消则两者都不落地。
5. 保存后回到卡片点「测试连接」，显示绿色延迟就通了。想改模型，点卡片「编辑」再进同一个弹窗。

### 省钱的建议：把七个任务分开配

「设置 → 任务分配」里可以给不同任务指定不同模型：

| 任务 | 建议 |
|---|---|
| 正文生成 | 便宜、快、文笔好的模型（DeepSeek Chat / Qwen-Max） |
| 大纲 / 体检 | 强推理模型（deepseek-reasoner / Claude Sonnet / Gemini Pro） |
| 润色 / 改写 | 和正文同款即可 |
| 摘要 | 最便宜的模型就够 |
| 起名 / 对话 | 便宜的即可 |

这样一本书的账单通常能压到「全用旗舰模型」的三分之一。

### 通用模式：跳出这本书（可选）

平时对话里，AI 手里一直握着这本书的资料（简介、设定、大纲、前文、当前章，最多两万 token），身份也是「这本书的写作搭档」。所以你问「明朝哪年建立的」，它答完事实还会顺手给你一段第 3 章的建议——因为书稿就在它眼前。

要问与本书无关的事，点开**「通用」**开关：

- 这一轮**不注入任何作品资料**，身份换成通用问答助手，只答你问的那件事；
- 如果配了搜索源（见下），还会先联网查一遍再回答；
- **检索词不是把问题原样丢出去**：会先用一次很小的请求把问题改写成 1–3 条搜索词，「今天/最近」这类词换成具体日期，长句拆成关键词；改写成什么样，展开回答下面的「来源 N 条」第一行就能看到；
- 开启时「可改稿」会自动置灰——看不到书稿就没得改，改也是凭想象改。

它不记忆，每轮自己决定；再点一下回到本书模式。

**配置**：设置 → 联网搜索 → 打开「启用联网搜索」→「新增搜索源」。如果你本来就用 DeepSeek 写稿，选 **DeepSeek 搜索**、**Key 留空**即可——它直接复用「渠道与模型」里那一把（同一个 Key，按成功请求计费，约 0.005 元/次，空结果不计费）。其它可选：**博查 Bocha**（国内直连，中文史料质量好）、智谱、Tavily（海外，需代理）、Serper，或自建 SearXNG（免费，但公共实例大多禁用了 JSON 接口）。Key 只存在本机钥匙串里，不写进 config.json，也不会发给任何模型。

**联网怎么配**：设置 → 联网搜索 → 打开「启用联网搜索」→「新增搜索源」。做法见下面一段。检索只在「通用」模式下发生——这本书内部的写法讨论不需要外部资料，有书稿就够了。

**来源在哪看**：开启通用 + 联网的那一轮，回答下面会出现「来源 N 条」，展开能看到标题与站点，点一条直接打开原文。

**它有意不做的四件事**：

- 不替你判断该不该查——是否联网由你按这一轮的问题决定（点「通用」就是要查外面的事）；
- 不查虚构体系（境界、流派、功法那类）。搜到的是别人小说里的设定，用了就是雷同，所以这类问题直接跳过检索；
- 查不到就明说「本轮未取得外部资料」，绝不假装查过，也不编造来源和 URL；
- 资料和本书设定冲突时，一律以本书设定为准。

**省钱**：单次 3–8 条（默认 5）；同一件事在缓存有效期内（默认 24 小时）重复问不重复计费；「先压缩再注入」会先用当前对话模型把结果压成要点，省上下文。检索词规划多一次很小的请求（最多 200 token），比一次搜错的检索便宜得多。

## 三、开一本书的三种方式

### 方式 1：AI 一键开书（最快）

书架右上角「✨ AI 一键开书」：

1. 写一句灵感（≥4 字），或点「换一个」用示例。
2. 选场景（默认长篇小说）、题材、每章字数。
3. 点「开始生成」，五步走下去：
   **书名与简介 → 核心设定 → 分卷大纲 → 首卷章纲 → 首章正文**
4. 每一步的产物都可以直接改；不满意可以单步「重新生成」，不影响别的步骤。
5. 最后点「写入书架并打开」，一本书就成型了。

> 每一步都是流式生成的，随时可以「停止」。如果模型返回的格式很乱，墨舟会尽量容错解析；实在解析不出来，会把原文放进可编辑框，你手工理一下再点「重新解析」。

### 方式 2：新建作品向导（最稳）

书架右上角「+ 新建作品」，四步：

1. **选择场景** —— 12 种，决定提示词、结构层级（卷/章 or 幕/场）、默认篇幅、快捷动作。
2. **题材与主题** —— 16 个题材（决定「读者期待什么」）+ 封面色。
3. **篇幅规划** —— 每章字数、全书目标（0 = 不限）、初始章节数。
4. **作品信息** —— 书名、作者、一句话灵感、故事梗概。

创建后会按你选的章节数生成占位章节，并按场景的结构模板建一份大纲骨架。

### 方式 3：导入已有的稿子

**整本导入到书架（推荐）**：书架工具条 →「导入书稿」，选一个 TXT / Markdown。向导四步：

1. **本地解析**：先按「第 X 卷 / 卷 X」切卷，再按「第 X 章 / 回 / 节」切章（Markdown 标题、「1. 标题」也认）；没有章节标记时按约 3000 字切块并提示。书名与作者会从正文首行、文件名、`作者：xxx` 里猜。
2. **AI 识别**（默认勾选，可跳过）：识别题材、一句话简介、故事梗概、主要人物，并给每章压摘要；可选按情节重新分卷。逐批显示进度，可随时停止；某一批失败会自动重试一次，仍失败也不影响导入，结束后列出没摘到的章。
3. **预览修正**：书名 / 作者 / 题材 / 简介 / 梗概 / 每章标题与摘要 / 是否收进这本书 / 是否生成大纲，全都能改。
4. **导入到书架**：章节直接记为「已完成」，每章挂回自己的大纲节点；大纲是「卷 → 章」两级。导入完自动进入写作台第一章。

**追加到当前作品**：写作台左下角 下载图标 →「导入 TXT / Markdown」，选中的文件会按「第 N 章 / Chapter N / # 标题」分章后**追加**到这本书末尾（适合分卷写、后来补稿）。

## 四、写作台导览

```
┌────┬──────────┬─────────────────────────┬──────────────┐
│ 写作│ 章节列表  │ 章节标题 / 快捷动作       │  AI 对话     │
│ 大纲│  01 第一..│ ─────────────────────── │  上下文      │
│ 设定│  02 第二..│  B I S H1 H2 " ≡ ↺     │              │
│ 灵感│  03 第三..│                         │  DeepSeek    │
│ 文风│          │       正文编辑区         │   ┌─────┐    │
│ 体检│   + 新章  │                         │   │对话  │    │
│ 统计│          │                         │   └─────┘    │
│    │          │ 本章 1200 / 目标 2500     │  [输入框]    │
└────┴──────────┴─────────────────────────┴──────────────┘
```

- **左栏图标**：写作 / 大纲 / 设定 / 灵感 / 文风 / 评书 / 体检 / 统计；最下面是「作品信息」和「导出整本」。
- **沉浸写作**：右上角 `沉浸` 或 ⌘⇧F，隐藏左栏 / 章节列表 / 按钮条 / 字数条，并自动进入系统全屏；按 Esc 或左上角「退出沉浸」回来。沉浸中 ⌘J 会把 AI 面板变成右侧浮层，不挤占正文宽度。
- **章节列表**：双击章节名改名，悬停右侧垃圾桶删除（会二次确认）。每章标题右侧的两个小图标是**本章梗概**（本子笔）和**历史版本**（时钟）：梗概图标有梗概时高亮、鼠标停上去能看全文，点一下查看/编辑（保存与清空都会同步到后续生成用的「更早章节梗概」），没有梗概时悬停才出现。
- **章节状态**：每章标题下的徽标显示 `待写` / `撰写中` / `已完成`，点一下循环切换。它和大纲页对应章节点的状态是**同一件事**——在哪边改，另一边立刻跟着变；正文从空变成有字时，`待写` 会自动转为 `撰写中`。
- **旁批栏**：工具栏「旁批 N」在右侧打开**当前章**的编辑批注，按段落升序；点一条就跳到正文那一段并高亮，可标记已处理 / 删除 / 重新批注本章。批注本身在「体检 → 段落侧批」里批量生成，两处看的是同一份数据（随作品保存）。正文改过之后，若批注的段落序号对不上，栏顶会出黄条提醒「重新批注本章」——它不会擅自清空你的批注。窗口较窄（不足 1500px）时，打开旁批会自动收起右侧 AI 面板，免得正文被两块侧栏挤没；⌘J 重新唤起 AI 时旁批会让位。
- **右上角动作**：`校读` `旁批 N` `润色` `续写` `重写本段` `沉浸`。正文搜索不再占按钮，直接按 ⌘F（Windows 上是 Ctrl+F），面板里可在「本章 / 全书」之间切换；搜索面板打开时右侧 AI 面板会自动让位，关掉搜索就回来（对话记录和正在生成的回复都不受影响）。
- **选中文字**会在编辑器上方浮出一条动作条：`扩写` `精简` `改写` `去 AI 味` + 当前场景的专属动作。
- **右侧 AI 面板**：⌘J 开关。「AI 对话」可以就这本书随便问，问的时候会把**当前这一章的正文**一并交给模型（不只是前文和设定）；「上下文」能看到这次请求到底喂了什么，第一块就是「当前章节〈标题〉正文」。
- **让它直接改稿**：对话里可以说「把最后一段改得更有余味」「全书『父亲』改成『大伯』」「顺手把第 3 章梗概更新了」。AI 会在回答后面附一段改动，气泡上出现 **`查看并应用 N 处修改`**——点开是逐条的改前/改后，**你没点应用之前，稿子一个字都不会动**。它能改的只有作品数据：正文段落（改/插/删）、跨章纯文本替换、章节梗概、大纲节点（标题/情节点/状态）、设定库条目。
  - 定位靠「原文片段」：AI 必须逐字抄一段正文，抄错了就标红「找不到原文」并跳过——**不会**自作主张重写整章。同样的话出现好几处时也只标出来，不改。
  - 应用后每章会留一份 `versions` 快照（章节版本历史里可回退），30 秒内还能整批撤销（面板右上角「撤销改稿」）。
  - **如果某一批改动全都「找不到原文」**：多半是 AI 用了**它自己在对话里写过的那一版**（你可能没采用，或后来另写了一版正文），而书里是另一版。预览顶部会说明这点，并给一个 **`让它重新读这一章再改`** 按钮——点一下它会重新照书里的真正文摘录，通常一次就对了。
  - 输入框右下角的 **`可改稿` / `只聊天`** 是这一功能的开关：点成「只聊天」后对话不再提改动，纯粹陪你聊。
  - 建议把「设置 → 输出预算 → 对话助手」保持在 12000 以上：改动块要把原文抄回来，比纯聊天更费额度。
- **让它建章、写稿**：说「补 29、30 章的大纲」只会加**大纲节点**（计划）；说「建第 30 章」会真的建出一章（并自动补一个同名大纲节点，章挂在这个节点上）；说「建第 30 章并写出来」则在你点「应用选中」之后**当场写初稿**，按这一章的目标字数整章生成、不足自动补写。
  - 预览里建章会展开成两条（`新增大纲节点` + `新增章节`），可以只勾一条：只要大纲不要章、或只要章不要大纲都行。
  - 写稿进度显示在面板顶部：`写作中 1240/2500`，旁边有 `停止`。**停下来的部分会留在正文里**，说「继续写第 30 章」可以接着写。
  - 写稿期间如果你在那一章自己动手打字，写稿会自动停下，不会覆盖你写的字。
  - 一轮最多写 2 章；说「建 5 章并都写出来」时前两章会写，其余只建章，面板会说明。
  - 写稿走「设置 → 输出预算 → 写作 → 正文生成」这份额度，用的是「正文模型」。
- **底部字数条**：本章字数 / 目标 / 全书字数 / 上下文 token 估算 / 自动保存状态。

### 篇幅是怎么被"管住"的

- 每章有 `targetWords`（新建时按场景默认值给）。生成后按**整章**算账：不足目标的 **90%** 自动补写（最多 3 轮），已经够长就停下。
- **这件事默认就开着**，不需要你去设置里开启什么「严格模式」。补写时界面底部会显示「篇幅不足（1200 / 2500 字），正在补写第 1 轮，还差约 1300 字…」，写完了会告诉你补了几轮。
- 补写只补差额：差 300 字就给 300 字的额度，不会因为「这一章还长」而让模型继续铺陈。
- 接着半句写（光标停在段落中间）时，目标仍按整章算：本章已有 2000 字、目标 2500 字，就只补那 500 字。
- 写过了目标不会自动删字——你的稿子机器不替你删。字数条上会变绿提示，删不删你自己定。
- **模型只思考、不写正文**怎么办：推理模型会先把整段思路想完再动笔，思考过程和正文共用同一份输出额度，想得越久留给正文的越少。墨舟会自动重试一次（并把额度抬高一半）；两次都空会明确告诉你原因，此时可以：① 把「正文模型」换成非推理模型（如 deepseek-chat）；② 到「设置 → 输出预算 → 写作 → 正文生成」把额度调大；③ 把本章目标字数调大后重来。
- 想改某章的目标，直接在章节上改 `targetWords`，或在底部字数条上看进度。

### AI 评书：把章节改写成能说出口的书

左栏「评书」页签：把已经写好的章节改写成**评书稿**，再用系统语音念出来。

- **范围**：本章 / 指定章节（多选）/ 全书。全书是逐章串行，可随时停止；某一章失败不影响后面的章，结束后列出失败章节与原因。
- **风格**：单田芳式 / 老北京说书 / 快节奏 / 悬疑夜场 / 少儿故事。五种风格的提示词不一样，不是换个名字。
- **时长**：1 / 3 / 5 分钟，约 260 / 780 / 1300 字。评书稿按「【回目】【定场诗】【正文】【收尾】」四段生成，要求口语化、短句、设扣子、**不复述原文**。
- **稿子可改**：每章生成完立即存进作品（不会覆盖正文）。手动改过的稿子，再点「重新生成」会先弹窗确认，避免把改好的稿子冲掉。
- **朗读**：点「播放」用系统语音逐句念，支持暂停 / 继续 / 停止、语速 0.7–1.5、中文音色选择，当前句会高亮。系统没有中文语音时按钮会置灰，并提示可以把评书稿导出到别处念。
- **导出**：「导出本页」把当前范围的评书稿拼成一份 Markdown（每章一个二级标题），默认文件名《书名》评书稿.md。
- 评书稿有独立预算项：「设置 → 输出预算 → 导入与评书 → AI 评书稿」，按目标字数计算。

## 五、大纲与设定

### 大纲
- 树是**两级**（长篇：卷 → 章；剧本：幕 → 场）。卷可折叠，标题行内改名，状态徽标点一下循环（待写 → 进行中 → 已完成）。章节点的状态与写作台里那一章共用，改一边两边同步。
- 章节行上标题在左、状态等标记在右，`已建章` 会点着跳到写作台那一章。就算你先手打大纲、后来才手工新建章节，只要标题对得上也会自动认成同一章（写作台里新建章节时也会按标题自动挂到大纲对应章节点上）。
- 「AI 生成大纲」：给一句指令（默认已填），流式生成后逐行可编辑 → 选择「替换现有」或「追加到后面」。
  - 指令里写了几章（如「生成 10 章」）就会校验：模型少写了会自动追写 1–2 轮；仍然不够时会明确提示「要求 10 章，实际只拿到 N 章」。
  - 预览里有「模型原文」：可以直接在原文里补齐章节、改格式，点「按原文重新解析」，支持「第X章 标题：情节点」、数字编号和表格三种写法。
- 每一章可以「AI 生成本章章纲」（写到该章的 `summary`），也可以「建为章节」把章纲变成真正的章节。
- 章节标题旁的「已建章」点一下就跳到写作台那一章。

### 设定
- **五个分区**：角色 / 世界观 / 术语 / 时间线 / 伏笔。
- 角色卡有 11 个字段（身份、外貌、性格、动机、缺陷、人物弧光、说话方式、关系、备注…）。**动机 + 缺陷 + 说话方式**这三项对生成质量影响最大，别省。
- 世界观条目可以单独关掉「对 AI 可见」——写反转时先把它藏起来，等揭晓了再打开。
- 伏笔台账记 `setup`（怎么埋的）和 `payoff`（怎么收的），体检功能会读它。
- 「AI 帮我补全」会先读你已有的设定，避免生成重复内容。

## 六、文风分身：让它写得像你

文风分身有两条路：**用别人现成的**，或者**提炼你自己的**。

### 6.1 从系统分身库引用（推荐先试这条）

设置 → **文风分身库**，内置 **100 位作者**，分六大流派：

| 分类 | 内容 | 数量 |
|---|---|---|
| 传统文学 | 鲁迅、沈从文、老舍、张爱玲、余华、莫言…… | 18 |
| 网文金牌 | 天蚕土豆、唐家三少、辰东、猫腻、爱潜水的乌贼、老鹰吃小鸡…… | 18 |
| 言情女性向 | 桐华、匪我思存、亦舒、顾漫、丁墨…… | 16 |
| 悬疑科幻 | 刘慈欣、紫金陈、马伯庸、雷米、周浩晖…… | 17 |
| 历史武侠 | 金庸、古龙、梁羽生、高阳、二月河、麦家…… | 16 |
| 新类型 | 三天两觉、小椴、榴弹怕水、乘橙…… | 15 |

书里怎么用：

1. 左栏「文风」→ **从分身库添加** → 搜索作者名（支持「古龙 短句」这种多词组合）→ 选中 → 「添加并绑定本书」。
2. 绑定后，这位作家的 **6–8 条可执行特征**会进每次生成的系统提示词。

**引用 ≠ 拷贝**：书里只存来源 ID，指向系统库那条。所以你在设置里改了某位作家的特征，**所有引用它的书立刻跟着变**，不用逐本去改。
想在这个基础上二次加工，就在添加时勾「拷贝一份到本书」，或者添加后点「编辑副本」。
如果系统库里那条被删了，书里会标「来源已删除」，但**仍按引用时的快照继续生效**——不会突然变成裸写。

> 种子库只收录特征卡和风格摘要，**不内置名家原文**（版权考虑）。想更贴近，可以自己往分身里补原文样本。

### 6.2 用你自己的样本创建

1. 左栏「文风」→「+ 新建分身」。
2. **喂样本**：1–5 段你自己写的东西，总量 ≤ 5000 字。
   - 最佳配比：一段对话 + 一段描写 + 一段心理 + 一段叙事推进。**覆盖比堆量更有效。**
   - 也可以点「从本书正文里取一段」直接引用已有章节。
3. **提炼特征**：AI 会输出 3–6 条**可执行**的规则（例如「短句为主，一句话不超过 20 字」「比喻只取自日常物件」）。可以手动改、删、加。
4. **试写对比**：输入一个引子，左边是不带分身、右边是带分身，同时生成。像不像一眼就看出来。
5. 「保存并绑定本书」。

### 6.3 管理分身库（设置 → 文风分身库）

- **搜索**：作者名、代表作、标签、特征内容都能搜；空格分隔多个词表示「都要命中」。
- **筛选**：按六大流派点卡片，或点任意标签；「仅看自建」筛出你自己建的。
- **新建 / 编辑 / 删除 / 复制**：每条右上角三个按钮。内置分身删掉后可以用右上角「恢复内置」找回。
- **AI 辅助**：新建时写一句「想要一个古龙式的江湖腔，短句多、留白多」，AI 直接产出特征卡；
  已经填了样本的，点「按样本优化」会照着你的样本改写；有草稿但不满意的，点「重新生成整套」。
- **恢复内置**：把 100 位内置分身恢复出厂内容，**你自己建的/复制的不受影响**。

同一时间只有一本分身对本书生效；切换开关会顶掉之前的绑定。

## 七、全书体检

左栏「体检」：

- **全书一致性**：先把每章压成梗概（已有摘要的直接复用），再把 角色 + 世界观 + 时间线 + 伏笔 + 全部梗概 一起交给模型审，输出带章节定位的问题卡（人物/时间线/设定/伏笔/逻辑）。点章节 chip 直接跳过去改。
- **章节体检**：节奏 / 冲突 / 悬念 / 注水 四项评分 + 具体问题。「注水」越高越糟。
  - 打分卡上如果某一项显示「**未评**」，意思是模型这次没给出这项的分数（常见于它改用一段文字回答、没按 JSON 格式输出）。这种情况评语仍然保留，可以直接参考；想要完整四项分数，再跑一次或换一个更听话的模型即可。系统不会为了凑满四项而编造分数。
- **伏笔盘点**：本地台账 + 「AI 找出正文里未登记的伏笔」→ 一键登记进台账。
- **段落侧批**：以老编辑的口气逐段写旁批（删 / 改 / 慢 / 快 / 虚 / 偏），**只提意见、不改正文**。详细用法见下一节。

### 段落侧批怎么用

体检页 › 段落侧批是**批量工作台**：

- **范围**：本章（下拉选章）/ 指定章节（多选，可全选 / 反选）/ 全书。0 字的章会自动跳过并说明。
- 开跑前会算清账：「将批注 N 章 · 合计 X 字 · 预计 N 次调用」；已有批注的章会注明「重跑会覆盖（已标记『已处理』的会保留）」。
- 跑的时候逐章显示进度、当前章与已收到字数，可随时**停止**。**停在章末**：已经完整拿到的章会保留，不会白花钱。
- 单章失败不中断，结束后列出「X 章成功 / Y 章失败」和每章原因；解析失败还能展开看模型原样返回。
- 结果按章分组，可按「全部 / 未处理 / 已处理」和六种批注类型筛选；每条可**跳到正文**（会切到写作台并选中那一段）、标记已处理、删除。
- 「清空全部」会二次确认。批注随作品保存在 `marginNotes` 里，关掉应用再打开还在。

写作页右侧「旁批 N」栏是**边写边看**的地方：只显示当前章，按段落升序，点一条就选中正文那一段；可重新批注本章、清空本章、标记已处理 / 删除。正文改动后若段落序号对不上，栏顶会出黄条，但**不会自动清空**你的批注。

> 批注是「编辑意见」，不是「改稿」。真要改，仍然由你自己动手——或用体检建议的「采用」走改前/改后对比。

### 体检建议可以直接采用

章节体检每条问题右边有一个**「采用」**按钮，点下去会：

1. 先按这条问题引用的原文片段（`evidence`）在正文里**找出它在哪一段**；
2. 只把那几段交给 AI 按建议改写，**其余段落逐字不动**；
3. 弹出「改前 / 改后」左右对比，你可以逐段点「跳过此段」；
4. 你点「写入正文」才会真的落盘。

几条使用要点：

- **只改被点名的段落**，不整章重写。整章重写会顺手改掉一批没问题的地方，对比根本审不过来。
- **定位不到就不改**。如果建议没给原文片段、或那段话在正文里找不到（比如正文已经改过、或问题来自章节梗概而非正文），会明确告诉你「这条建议定位不到具体段落」，绝不去改别的地方。
- **对比期间正文被改过**（例如你在另一个窗口编辑了这一章），写入时会拦下来让你重新点一次，避免把新内容写错位置。
- **全书一致性的问题同样可以「采用」**，并且会**跨章统一口径**。它和章节体检的区别在于证据来源：全书体检的证据摘自章节梗概，跟正文不会一字不差，所以系统会按相似度在涉及章节里找候选段落，并把「我猜的是这几段」明写在弹窗上；涉及多章时，对比列表**按章分组**显示，一次把各章说法改一致。
- **可以逐段跳过**。跨章采用时尤其有用：如果你只想改其中一章的口径，把另一章的「跳过此段」点掉即可。
- **定位是按「人名、地名等实词」判断的**。只和证据共享几个常见词（比如都提到「急诊室」）的段落不会被当成目标——那种改动往往只是把无关段落润色一遍，矛盾还在。所以偶尔会看到「体检提到 3 章，其中 2 章没找到对应正文」：这是如实告诉你只改了能找到的部分。
- **措辞不同也能找到**。全书体检读的是章节梗概，模型写出的证据常是转述（「当成了已故的妻子」而正文写「认作亡妻」），系统允许这种出入，仍能定位到正确段落。
- **建议里点名了哪一章，就优先去那一章找**。即使模型把涉及章节填错或漏填，只要建议写着「把第 1 章的……改为……」，就会先在第 1 章里定位。
- **如果模型只是把段落重述一遍**（看着改了，但建议里的“把 X 改为 Y”没落实），弹窗会提醒你这次改动可能没解决问题。
- 对比里只给**真正变化的字词**标红/标绿，改了两个词也能一眼看出来。
- 采用建议会消耗一次改写调用的 token（预算项：「设置 → 输出预算 → 写作 → 选中段落润色」）。

> 体检会消耗 token（尤其全书体检）。建议在**每写完一卷**做一次，而不是每章。

## 八、上下文面板：不做黑箱

右侧「上下文」标签页会实时显示：

- 总预算（默认 24000 tokens）与当前占用百分比
- 每一块资料（简介/题材/角色/世界观/大纲/前文/文风）分别占多少 token
- 超预算时哪一块被裁掉了（裁剪顺序：更早的章节 → 术语 → 线索 → 世界观 → 前文 → 角色）

如果发现「AI 忘了前情」，先来这里看是不是大纲/角色被裁了。省 token 的办法：把过期章节的正文压成摘要（章节列表里的梗概图标 →「让 AI 重新生成」），摘要比正文便宜得多。

## 十一、常见问题

**Q：点了生成没反应 / 报「还没有可用模型」**
A：去「设置 → 渠道与模型」确认渠道是启用状态，并且「任务分配 → 正文生成」有指定模型。

**Q：报「API Key 无效或没有权限」**
A：Key 复制时多了空格；或者这个 Key 没有该模型的权限；或者余额用完了。先点「测试连接」看具体报错。

**Q：点了生成，一直停在「模型正在思考…」，是不是超时了？**
A：不是。思考类模型（deepseek-reasoner、Qwen3 系等）会先想很久再动笔，弹窗里的「已 N 字」和「已等待 N 秒」会持续跳动，只要数字在变就说明连接正常。墨舟只在连续 3 分钟完全没有进展（连心跳都没有）时才中止，并会写明原因。如果每次都等太久，建议在「设置 → 任务分配」里把「大纲推演」换成更快的不思考模型。

**Q：生成写到一半断了**
A：多半是网络或厂商限流。墨舟不会丢已生成的内容（流式的部分已经进了弹窗），可以直接「重新生成」或先采纳再手工补。

**Q：AI 老是忘设定 / 人物崩**
A：① 检查「设定 → 角色」里的动机和说话方式是否具体；② 检查上下文面板是不是被裁了；③ 把前几章压成梗概；④ 在「写作偏好 → 作者额外要求」里写死几条硬规则。

**Q：Word 导出的中文字体不对**
A：docx 里写的是「宋体 / 黑体」，Windows 一定有；macOS 没有宋体会自动回退到系统衬线体，视觉上接近。

**Q：能不能多台电脑同步？**
A：把数据目录放进 iCloud / OneDrive / 坚果云，然后用 `MOZHOU_USER_DATA` 指过去。注意别两台同时开着写同一本书（没有做冲突合并）。

**Q：我的 Key 安全吗？**
A：Key 用系统钥匙串加密存在本机 `secrets.json` 里；请求从主进程直连你填的 BaseURL，不经过任何第三方服务器。但如果你的电脑被完全控制，任何本地软件都拦不住——这是本地优先的代价。
